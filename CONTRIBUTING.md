# Contributing to Mason AI Platform

Thank you for your interest in contributing to Mason AI Platform.

We welcome developers, AI engineers, designers, educators, and open-source contributors.

## How to Contribute

1. Fork this repository.
2. Create a new branch for your feature or bug fix.
3. Make your changes.
4. Test your code.
5. Submit a Pull Request.

## Coding Standards

- Write clean and readable code.
- Follow project architecture.
- Use meaningful commit messages.
- Document new features.

## Reporting Issues

If you find a bug, please create an Issue with:

- Description
- Steps to reproduce
- Expected behavior
- Screenshots (if applicable)

## Feature Requests

We welcome new ideas.

Before submitting a feature request, please check whether a similar request already exists.

## Code Review

Every Pull Request will be reviewed before merging.

Please make sure your code passes all tests.

## Community Rules

- Be respectful.
- Help others.
- Share knowledge.
- Keep discussions professional.
